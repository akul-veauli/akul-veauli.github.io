Introduction

About Me

I sit at the intersection of automation and valuation: I write Python engines that pull raw SEC filings and turn them into fully live-formula Excel models, and I build those same models by hand when the judgment calls need a human doing them. That combination, someone who can underwrite a deal rigorously and also build the tool that does it faster, is what your team would be hiring.

I'm not the strongest generalist candidate on paper. I am, on the evidence below, the best automation-and-valuation analyst you're going to find at this level.

Independent Work

Projects

A family of Python-based valuation tools that pull live filings data and generate institutional-style, fully live-formula Excel workbooks. This is the work I'd point to first.

Automated DCF Valuation Engine

PYTHON · SEC EDGAR · EXCEL AUTOMATION

End-to-end DCF pipeline pulling SEC EDGAR companyfacts, Damodaran datasets, Yahoo Finance, and FRED into 10-year forecasts with WACC builds, sensitivity grids, and scenario analysis, all delivered as live-formula Excel workbooks. Includes a 44-check validation suite with SHA-256 provenance fingerprinting so no workbook built on superseded code can validate clean.

PythonXBRLValidation SuiteDCF

LBO / Take-Private Modeller

PYTHON · LIVE-FORMULA WORKBOOKS

Give it a ticker and it builds an eight-tab LBO workbook: Sources & Uses, operating model, tranche-level debt schedule with senior-first cash sweep, IRR/MOIC returns with a value-creation bridge, and sensitivity heat maps. Every cell is a real Excel formula driven by an editable Inputs sheet, verified by recalculating the workbook against the Python engine.

PythonLBODebt SchedulesTested

Debt Capacity Analyzer

PYTHON · CREDIT ANALYSIS

Credit-side sibling of the DCF and LBO tools: a leverage and coverage ratio engine with credit scoring and downside stress testing to gauge how much debt a business can actually support.

PythonCredit RatiosStress Testing

Investment Memo Creator

PYTHON · DEAL WRITE-UPS
